Validar Cédula Ecuatoriana

Verifica si un número de cédula tiene el formato correcto según el algoritmo estándar de verificación (módulo 10). Validación instantánea, sin consumir créditos.

10 dígitos — los 2 primeros indican la provincia (01-24)

¿Cómo funciona la validación?

La cédula ecuatoriana usa un algoritmo de verificación basado en el módulo 10:

  1. Los 2 primeros dígitos indican la provincia (01-24)
  2. El tercer dígito debe ser menor que 6
  3. Los dígitos impares se multiplican por 2 (si ≥ 10, se resta 9)
  4. Los pares se multiplican por 1
  5. El dígito verificador (posición 10) completa la decena superior

Ejemplo de código (Python)

def validar_cedula(c):
    if len(c) != 10 or not c.isdigit():
        return False
    prov = int(c[:2])
    if prov < 1 or prov > 24:
        return False
    coef = [2, 1, 2, 1, 2, 1, 2, 1, 2]
    total = 0
    for i in range(9):
        v = int(c[i]) * coef[i]
        if v >= 10: v -= 9
        total += v
    check = 0 if total % 10 == 0 else 10 - (total % 10)
    return check == int(c[9])

Validar vs Consultar

Validar solo verifica la estructura matemática. Consultar obtiene la información de la persona desde fuentes públicas, al instante.
